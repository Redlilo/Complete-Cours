Apprendre à s'en servir

Vous n'avez rien à installer ni à mémoriser. Les phrases ci-dessous se copient telles quelles.

  • Trois façons de déclencher

    Tapez /nom-du-skill, décrivez la tâche avec vos mots, ou écrivez « utilise le skill X ». La deuxième suffit presque toujours : je choisis le skill adapté et je le charge.

  • Un skill par tâche

    Un skill est un mode d'emploi chargé à la demande. Demandez une tâche à la fois et nommez le résultat attendu : un fichier, un lien, un rapport.

  • Précisez ce qui compte

    Donnez le format (.xlsx, .pdf), l'emplacement des fichiers, le public visé. Cela évite les allers-retours.

  • Les skills de plugin

    Ils portent un préfixe : token-shield:stats, planning-skills:shaping. Tapez / pour voir la liste dans l'app.

  • Rien n'est envoyé sans vous

    Envoi de message, publication, suppression, achat : je demande d'abord. Un skill ne change pas cette règle.

Huit demandes à essayer

  • xlsx
    Fais-moi un tableur de budget mensuel en .xlsx avec totaux par catégorie.

    Sans écrire le nom du skill : la demande suffit.

  • pdf
    Fusionne ces deux PDF et supprime la page 3.

    Donnez les chemins des fichiers.

  • deep-research
    Fais une recherche approfondie sur les meilleurs outils de prise de notes et compare-les.

    Je lance des sous-agents et rends un rapport.

  • code-review
    /code-review high

    Le niveau va de low à max. Sans niveau, je reprends le dernier.

  • loop
    /loop 5m vérifie si le déploiement est terminé

    Sans durée, je choisis le rythme.

  • schedule
    /schedule rappelle-moi demain à 15h de relancer le devis

    Aussi pour des tâches récurrentes.

  • token-shield
    /token-shield:stats

    Les skills de plugin s'écrivent plugin:skill.

  • skill-creator
    Crée un skill qui résume mes comptes rendus de réunion

    Je le teste avant de vous le rendre.
